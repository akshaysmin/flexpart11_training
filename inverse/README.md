# Inverse Modelling with FLEXPART

This exercise is designed to introduce participants to the basics of inverse modelling using FLEXPART. Inverse modelling is a powerful technique that allows researchers to estimate the sources of atmospheric pollutants based on observed concentrations and transport patterns. However, running all applications to use FLEXINVERT is not possible in this training due to time constraints. Instead, we will focus on the basic principles of inverse modelling and provide participants with a hands-on experience using a simplified version of FLEXINVERT.
