# Inverse Modelling with FLEXPART

This exercise is designed to introduce participants to the basics of inverse modelling using FLEXPART. Inverse modelling is a powerful technique that allows researchers to estimate the sources of atmospheric pollutants based on observed concentrations and transport patterns. However, running all applications to use FLEXINVERT is not possible in this simplified training due to resources and time constraints. Instead, we will focus on the basic principles of inverse modelling and provide participants with a hands-on experience using a simplified version of FLEXINVERT.

To get started, participants should start with the [Introduction](./Introduction.ipynb) notebook, which provides an overview of the input data and should help in setting up the simulation. The next step is to run the [Emissions](./Emissions.ipynb) notebook, which covers the preparation of emission data for the inverse modelling process. And finally, participants can run the [Inverse Modelling](./Inversion.ipynb) notebook, which demonstrates the inverse modelling process using the prepared emission data and observed concentrations.
