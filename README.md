# FLEXPART11 Training

> @ALL: Welcome to the FLEXPART11 training! This training is designed for researchers and students interested in learning how to use the FLEXPART11 model for various atmospheric research applications.

The training will take place online from 23. to 25. September 2026. It will be focused on running FLEXPART11 for various research applications (e.g., volcanoes, radionuclides, greenhouse gases) and consist of lectures followed by practical hands-on sessions.

## Hands-on sessions
During the hands-on sessions, participants will have the opportunity to run FLEXPART11 simulations on their own computers or on Binder. The trainers will provide guidance and support throughout the sessions. Participants are encouraged to bring their own laptops and have FLEXPART11 installed beforehand.

![binder-logo](https://bids.mybinder.org/static/logo.svg?v=fe52c40adc69454ba7536393f76ebd715e5fb75f5feafe16a27c47483eabf3311c14ed9fda905c49915d6dbf369ae68fb855a40dd05489a7b9542a9ee532e92b)

Thanks to myBinder we can provide a cloud-based environment for running FLEXPART11 simulations without the need for local installation. Participants can access the Binder environment using the following link: [FLEXPART11 Binder](https://bids.mybinder.org/v2/gh/duetschm/flexpart11_training.git/HEAD).



## Documentation

Most information about FLEXPART can be found on [flexpart.eu](https://flexpart.eu/). The website contains a comprehensive overview of the model, its capabilities, and its applications. It also includes links to publications, tutorials, and other resources.

The documentation for FLEXPART11 can be found in the [FLEXPART11 Gitlab repository](https://gitlab.phaidra.org/flexpart/flexpart) at UNIVIE. It includes a user manual, installation instructions, and examples for various applications. The Documentation is hosted here: [https://flexpart.img.univie.ac.at/docs/](https://flexpart.img.univie.ac.at/docs/)

The documentation of FLEXINVERT can be found in the [FLEXINVERT Gitlab repository](https://git.nilu.no/flexpart/flexinvertplus) at NILU.
